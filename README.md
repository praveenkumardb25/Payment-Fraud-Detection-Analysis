# Payment Fraud Detection & Analysis

## Project Overview
An end-to-end Payment Fraud Detection and Analysis project using Python, MySQL, and Power BI. This project analyses 60 lakh+ transaction records to identify fraudulent transaction patterns, understand payment behaviour, and generate actionable business insights.

## Business Objective
- Identify fraudulent and legitimate transactions.
- Analyse transaction patterns and payment types.
- Understand fraud distribution and transaction behaviour.
- Identify high-risk transaction categories.
- Develop interactive dashboards for business decision-making.
